# Volantes Cursors (Pre-built)

A pre-built distribution of the popular **Volantes Cursors** theme, ready for immediate installation and use without needing to build from source.

---

## 📌 About This Repository

This repository provides **ready-to-use / compiled binaries** of the Volantes cursor theme. 

The original project requires building from source graphics. This repo is maintained for convenience, allowing users and package maintainers to quickly download and install the pre-built cursor files.

> **Note:** All credit for the original design, graphics, and cursor source files goes to the original creator, **varlesh**.

## 🚀 Installation

### Manual Installation

1. Cloning Repository
```bash
   git clone https://github.com/satellaos-official/volantes-cursors-compiled.git "$HOME/volantes-cursors-compiled"
```
   
2. Installation for User

```bash
bash $HOME/volantes-cursors-compiled/install.sh -u
```

3. Installation for System

```bash
sudo bash $HOME/volantes-cursors-compiled/install.sh -s
```

4. Installation for /etc/skel

```bash
sudo bash $HOME/volantes-cursors-compiled/install.sh -a
```
